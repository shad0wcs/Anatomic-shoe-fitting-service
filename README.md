# KolotovStep - сервис индивидуального подбора обуви.

Веб-сервис автоматического подбора обуви для людей с анатомическими особенностями стопы. Пользователь фотографирует стопу – нейросеть определяет три ключевых параметра (тип свода, пронацию, ширину) и подбирает подходящие модели из каталога.

Проект был написан в рамках ВКР Бакалавриат ГУАП 2026.

---

## Как работает

```
Фото стопы
    ↓
Валидация (стопа / не стопа) — 98.5%
    ↓
CNN-анализ трёх параметров (MobileNetV2)
    ↓
Взвешенный скоринг по каталогу MySQL
    ↓
Топ-N рекомендаций
```

**Параметры анализа**
- Свод стопы – отсутствует / низкий / средний / высокий
- Пронация – гиперпронация / нейтральная / супинация
- Ширина – узкая / стандартная / широкая / очень широкая

**Алгоритм подбора обуви**
```
Балл = свод * 35 + пронация * 30 + ширина * 20 + амортизация * 15
```
Совместимость параметров определяется матрицами. Модели с ортопедической адаптацией получают бонус +5 при плоскостопии.

## Установка и запуск

### Требования
- Python 3.9–3.11
- MySQL 8+
- 4 GB RAM (для инференса CNN)
### 1. Клонировать репозиторий
```bash
git clone https://github.com/ваш_ник/ShoeService.git
cd ShoeService
```
 
### 2. Установить зависимости
```bash
pip install -r requirements.txt
```
 
### 3. Настроить базу данных
Создать БД и заполнить её – запустить `shoe_service_db.sql` в MySQL Workbench.
 
Создать файл `.env` из шаблона:
```bash
cp .env.example .env
```
Заполнить своими данными:
```
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=ваш_пароль
DB_NAME=shoe_service
```
 
### 4. Обучить модели
 
> Модели не включены в репозиторий из-за большого размера. Нужно обучить самостоятельно.
 
```bash
# Генерация синтетического датасета (5500 изображений, ~2 мин)
python generate_dataset.py
 
# Обучение трёх классификаторов (arch, pronation, width) — ~30 мин CPU
python train_model.py
 
# Генерация датасета для валидатора
python generate_validation_dataset.py
 
# Обучение валидатора (стопа / не стопа) — ~10 мин CPU
python train_validator.py
```
 
После обучения в папке `models/` появятся файлы:
```
models/
├── arch.keras
├── arch_classes.json
├── pronation.keras
├── pronation_classes.json
├── width.keras
├── width_classes.json
├── validate.keras
└── validate_classes.json
```
 
### 5. Запустить сервер
 
```bash
python -m uvicorn app:app --reload
```
 
Сервер запустится на `http://localhost:8000`.
Документация API (Swagger): `http://localhost:8000/docs`
 
### 6. Открыть интерфейс
 
```bash
python -m http.server 3000
```
 
Открыть в браузере: `http://localhost:3000/index.html`
 
### Запуск с телефона (в одной Wi-Fi сети)
 
```bash
# Узнать IP компьютера
ipconfig  # Windows
ifconfig  # Mac/Linux
 
# Запустить сервер доступный по сети
python -m uvicorn app:app --host 0.0.0.0 --port 8000 --reload
```
 
В `index.html` заменить:
```javascript
const API = 'http://localhost:8000';
// на
const API = 'http://192.168.X.X:8000';
```
 
Открыть с телефона: `http://192.168.X.X:3000/index.html`

## Как сфотографировать стопу
 
1. Положите белый лист А4 на пол
2. Встаньте на лист, распределите вес равномерно на обе ноги
3. Держите телефон горизонтально над стопой на высоте 40–50 см
4. Стопа должна занимать 60–70% кадра
5. Снимайте при дневном свете без резких теней
> Если точность ниже 70% – переснимите фото при лучшем освещении.

## Ограничения и перспективы
 
**Текущие ограничения:**
- Точность классификаторов ограничена из-за domain gap между синтетическими обучающими данными и реальными фото
- Валидатор может пропускать нестандартные нерелевантные изображения
**Планируется:**
- Сбор реального датасета плантограмм (500–1000 фото) → точность 80–85%
- Мобильное приложение
- Интеграция с онлайн-магазинами
- История анализов пользователя
